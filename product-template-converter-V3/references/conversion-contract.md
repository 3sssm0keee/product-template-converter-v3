# 固定模板转换合同

## 输入路由

| 输入 | 标准化与盘点 |
|---|---|
| PDF | 提取文字、表格和原始图片；无文本层页面必须逐页渲染并 OCR 后进入源清单 |
| DOC | 用 Word 或 WPS 另存为 DOCX 后盘点 |
| DOCX | 盘点段落、表格、媒体、页眉页脚、分节、批注、链接和元数据 |
| PPT | 用 PowerPoint 或 WPS 另存为 PPTX 后盘点 |
| PPTX | 盘点幻灯片、母版、版式、形状、图片、备注、批注和媒体 |

内容始终填入内置模板包，不接受运行时传入任意 DOCX 模板。默认模板包为 `zxty-fixed-v1`；用户要求任意自定义模板时应改用通用模板转换 skill。最终交付规则见 `references/delivery-contract.md`。

## 内容规则

- 原技术参数、设备功能、数据、限制条件、单位和有效图片不缩减，不用概述替代原文。
- 可以重新分类；固定六个一级篇章各出现一次并保持既定顺序。无来源资质时保留“六、产品资质”标题，但不合成资质文案。
- 前五个业务篇章必须各有来源支撑内容；任一篇章为空时进入 `HUMAN_REVIEW`，不得以占位、复制或编造内容补齐。只有“六、产品资质”允许在源件无资质事实时保留空正文。
- “设备功能”“系统功能”“功能模块”等统一归入 `二、功能介绍`，只能作为无数字二级分类，不得生成重复主篇章。
- 删除源 `5.1` 等旧章节号和无意义条目号；保留模板一级中文编号。
- 技术参数表不设置序号列。源表含序号列时删除该列，但“技术项目/技术参数”等其余单元格逐字保留。
- 不添加“（续）”或重复主标题。标题不能孤立在页尾；正文句子、单个功能条目和表格行不得跨页拆断。
- 缺少型号、场景或其他前五章必要事实时保持对应内容槽为空并转入 `HUMAN_REVIEW`；缺少资质事实时仅保留固定篇章标题，不合成资质文案。成品正文不得显示 `待核实`、`TBD`、`XX` 等占位。
- 疑似原文错字、单位或数值不擅自纠正，原样保留并报告。
- OCR 文本必须标记来源页；出现型号、数值、单位或关键术语误识别时必须进入 `human_review`，不得把低置信 OCR 当作已核准原文交付。

## 图片与厂家身份

- 源有产品主图时放入封面；没有时删除模板示例产品图并留空。
- 产品图带大面积白底时只去除背景并紧裁设备主体，不改变设备结构、接口文字、视角或比例。
- 正文有效技术图和产品图全部保留；来源厂家的版式背景、Logo、联系方式条带和二维码删除。
- 厂家词表必须覆盖中文名、英文名、简称、品牌、域名、电话、邮箱和地址；扫描正文、表格、页眉页脚、形状、链接、元数据和可见图片。
- 含图片源件必须在交付前使用 Windows Media OCR 或 Tesseract（中文+英文）扫描渲染页；PDF 中的 JP2/JPEG2000、CMYK 图片必须先转成兼容 PNG，再嵌入 DOCX。

## 排版与兼容性

- 从模板副本编辑，保留固定媒体、页面大小、边距、底图、页眉页脚、页码和封底分节。
- 标题具有 Word/WPS 可识别的大纲级别；清除无意的自动编号、段落边框、`pageBreakBefore` 和无意义的多段 `keepNext` 长链。六个固定一级标题必须只与下一内容做一跳绑定；正文标签或段落后紧跟图片容器时，该段落必须只与对应图片做一跳绑定。
- 表格固定列宽、明确单元格边距、非固定行高、行禁拆；跨页重复表头。
- 清除空段落和不必要手动分页，正文自然续排且无异常大面积空档。
