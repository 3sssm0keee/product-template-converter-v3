# 固定模板合同

- 文件：`assets/ZXTY-XX_产品全称-产品介绍-模板.docx`
- SHA-256：`90B04F4C802A3821234B7A47789CCB47904C7D8E5C486087EC54953A39D19E70`
- 格式：A4 DOCX；原模板由 WPS 渲染为 5 页。
- OOXML：2 个分节、`header1.xml`、`header2.xml`、`footer1.xml`、`footer2.xml`。
- 固定视觉：4 个非空模板媒体对象的字节哈希必须保留。
- 第 1 页：固定封面；替换型号、产品全称和产品图。封面开头的产品型号/全称与“产 品 介 绍”必须按模板保持白色文字 `FFFFFF`；源无产品图时删除示例图并留空。
- 正文：保持模板背景、页眉、页脚、页码、字体与标题层级。
- 最后一页：第 2 节独立固定封底；不得显示正文页眉、正文页脚、正文页码或正文内容。

一级篇章顺序固定且各出现一次：

1. `一、产品简介`
2. `二、功能介绍`
3. `三、产品优势`
4. `四、应用场景`
5. `五、技术参数`
6. `六、产品资质`

其中“六、产品资质”的正文为事实驱动内容：无论来源是否存在资质内容，固定标题都必须保留且只能出现一次；来源没有资质事实时不生成正文，不得编造、占位或替代。

最终文件名：`<产品型号>_<产品全称>-产品介绍.docx`。
