# 强制失败防护

| 触发条件 | 强制处理 | 通过标准 |
|---|---|---|
| 固定封底继承正文 | 保持第 2 节及独立页眉页脚关系 | 最后一页只有固定封底 |
| 封面开头产品文字非白色 | 按模板将产品型号/全称和“产 品 介 绍”设为 `FFFFFF` | 深色封面背景上文字为白色，不能沿用 PX1 错误橙色 |
| 多个功能类标题 | 合并到唯一“二、功能介绍” | 六个一级篇章各一次 |
| 长参数表 | 行禁拆、表头重复、均衡跨页 | 无孤立少量尾行和大空档 |
| 内容间手动分页或保持链 | 清除无意义分页、空段和多段 `keepNext` 长链；保留固定标题到下一内容、图片标签到对应图片的一跳绑定 | 自然连续，无“（续）”，无孤立页尾标题或标签图片分离 |
| 源无产品图 | 删除示例图，不生成替代图 | 封面图片区为空 |
| 产品图有白色画布 | 透明去底并按主体紧裁 | 仅见完整设备，无白块/棋盘格 |
| 原件缺资质事实 | 成品留空，交付报告列待核实 | 正文无可见占位或杜撰 |
| 厂家身份嵌在图片或元数据 | 视觉检查并扫描 OOXML/关系/属性 | 来源厂家词和 Logo 零命中 |
| OCR 后端、中文语言包或 JP2 解码缺失 | 安装后自检直接 `BLOCKED` 并输出补全动作 | 不进入授权、盘点或半成品构建 |
| 图片型 PDF 无文本层 | 渲染页面并把 OCR 文本写入源清单 | OCR 内容有误识别时进入 `human_review`，不能静默交付 |
| PDF 提取出 JP2/CMYK 图片 | 构建前解码并转为 Word/WPS 兼容 PNG | 图片完整嵌入，无 `IMAGE_INSERT_FAILED` |
| 编辑后只做结构检查 | Word/WPS 双导出并逐页 PNG 比较 | 两套导出均完成且无阻断级可见缺陷 |
