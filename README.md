# V3 可移植分发修订

本包基于已完成本地验收的 V3 制作，整理模板范围、移除个人来源路径与外部案例名称，并注册已获用户批准的独立可移植模板。不是新的功能版本验收声明。

## 变化

- 保留第一模板 zxty-fixed-v1@1.0.0，第二模板改用 second-template-portable-v3@1.0.0。
- 排除旧第二模板 v1、v2 及专用于旧 v1 的历史 onboarding 辅助脚本。
- 第二模板 DOCX、重建候选、槽位业务定义及编译操作与原验收版本一致；IR 仅来源路径改变，并重新生成技术绑定及有效模板批准回执。
- 外部案例索引移除个人目录和具体客户案例名称。

## 验证范围

已核验 139 个清单文件、ZIP 完整性、解压后逐文件 SHA 和两套模板加载。保留的 70 个运行脚本逐字节未变。原交付基线保持不变。新模板注册与基础依赖预检通过；本任务先前已重新完成该模板的 Word/WPS 原件与候选导出，每引擎 2 页，同引擎逐页差异为 0。

用户明确取消此次分发任务中重复的业务批准、全矩阵和盲验。原 510 项测试、16 案例及视觉复验属于原基线；本次没有重跑，不将其声称为新 manifest 的整版验收。使用原报告调用原生发布门禁仍返回 RELEASE_HOLD，该结果保留，未修改验证器或历史报告。

## 使用边界

日常新任务请显式使用上述模板 ID。历史内容 decision/receipt 中的旧模板 ID 和哈希不会因分发包更新自动迁移，不要把旧回执直接用作新版有效回执。

ZIP 仅包含运行白名单与 manifest，不包含客户源件、完整开发证据、页面截图、缓存或本机依赖报告。Python、Office/WPS、Poppler、OCR 等外部依赖仍需使用环境具备。用户已明确允许随本公开版本发布模板中的公司名称、Logo、联系方式、二维码及作者元数据。
